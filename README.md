# TaskFlow - To Do List App

A responsive To-Do List application built using HTML, CSS, and Vanilla JavaScript.

## Features

- Add tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Total, Completed, and Pending counters
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

Created as part of a Web Development Internship.
